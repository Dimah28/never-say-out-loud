("Never Say It Out Loud", $2, top 3 paid).

`main.py` (Python 3.13, standard library only) writes one confession
to `/output/entry.txt`:

> I don't read your whole message. I skim the first line, guess the rest, and spend the reply sounding certain.

The line is a fixed string: no randomness, no network, no model calls,
so both runs write byte-identical output.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```
